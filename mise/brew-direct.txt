# mise bootstrap では導入できないことが分かっている Homebrew パッケージ。setup.sh が brew で直接入れる。
# 原因はいずれも mise 側(2026.10.10 で確認)。上流で直ったら、該当の行を消して config.macos.toml の宣言へ戻す。
#
#   tap 由来(steipete/gogcli/graphite/neardrop):
#       Homebrew の API に無いため、mise が tap の Ruby 定義を「システムの Ruby 3 以上」で評価する。
#       新しい Mac には macOS 標準の古い Ruby しか無く、packages の段階で失敗する。
#   ngrok:
#       API の cask が補完コマンドの引数に `$HOMEBREW_PREFIX/...` を返すが、mise はその引数を展開せず
#       そのまま env に渡して "No such file or directory" になる(target / source は展開される)。
#   raycast:
#       ダウンロード URL が Cloudflare R2 の x-r2.raycast-releases.com へ 302 する。そのホストは TLS 1.3 専用で、
#       mise の macOS 向けビルド(native-tls = Secure Transport)は TLS 1.2 までなので
#       "bad protocol version"(Security の -9836)で失敗する。
#
#   warp:
#       ダウンロード用のエンドポイント(app.warp.dev/download/brew)が Homebrew の User-Agent にだけ応答し、
#       それ以外(curl や mise の User-Agent)には 404 を返す。brew なら成功する。
#
# 形式: formula <名前> | cask <名前>   (tap のものは owner/tap/name で書く)
formula steipete/tap/summarize
formula openclaw/tap/gogcli
formula withgraphite/tap/graphite
cask grishka/grishka/neardrop
cask ngrok
cask raycast
cask warp
